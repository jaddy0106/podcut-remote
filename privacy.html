PODcut 개인정보처리방침

시행일: 2026년 11월 22일

이 방침은 데스크톱 앱 PODcut의 「유튜브에 올리기」 기능이 Google 계정과 YouTube 데이터를 어떻게 다루는지 설명합니다.

1. 받는 권한

사용자가 앱 설정에서 채널을 연결할 때 Google 계정으로 YouTube 권한(youtube.force-ssl)을 허락받습니다. 이 권한으로 앱은 다음 일만 합니다.

  • 연결된 채널의 이름과 재생목록 목록을 읽어 앱 화면에 보여 줍니다.
  • 사용자가 고른 영상을 그 채널에 올리고, 사용자가 정한 제목·설명·태그·공개 상태를 넣습니다.
  • 사용자가 고른 자막 파일을 그 영상에 붙이고, 사용자가 고른 재생목록에 넣습니다.

앱은 사용자가 올리기를 누르지 않은 채널의 영상, 댓글, 구독자, 시청 기록 등은 읽거나 바꾸지 않습니다.

2. 보관

  • Google이 주는 로그인 정보(갱신 토큰)는 사용자 컴퓨터의 운영체제 보안 저장소(macOS 키체인, Windows 자격 증명 관리자)에만 저장합니다.
  • 이 정보와 YouTube 데이터를 PODcut 개발자나 다른 서버로 보내거나 모으지 않습니다. 앱은 사용자 컴퓨터에서 Google에 직접 연결합니다.
  • 올리는 영상과 자막은 사용자 컴퓨터의 파일을 YouTube로 바로 보냅니다.

3. 제공·판매

Google 사용자 데이터를 제3자에게 제공하거나 판매하지 않고, 광고에 쓰지 않습니다. PODcut의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 연결 끊기와 삭제

  • 앱의 설정 › 유튜브 › 연결 끊기를 누르면 Google에 권한을 돌려주고, 컴퓨터에 저장한 로그인 정보를 지웁니다.
  • Google 계정의 서드파티 액세스 관리에서도 언제든 권한을 해제할 수 있습니다.
